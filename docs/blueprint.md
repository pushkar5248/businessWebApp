# **App Name**: Adhunik Invoicer

## Core Features:

- Inventory Management: Maintain and categorize stock items; allow adding, editing, and deleting items. Auto-update stock quantities on each transaction.
- Data Import/Export: Import bulk stock data from CSV, export complete data to CSV/Excel, and allow emptying the inventory database.
- Customizable Columns: Add, rename, hide, and delete columns in the stock table with custom formatting and local preference saving.
- Invoice Generation: Generate professional tax invoices with auto-calculated subtotals, taxes, and grand total; convert the final amount into words.
- Invoice PDF Generation: The app uses a tool to incorporate required business, customer and product variables into a PDF, with the same look as the client's template.
- Purchase/Sales History: Track purchases/sales with filtering, sorting, and search capabilities.
- Customizable Settings: Offer light/dark modes, font choices, table color customizations, and editable bill footers.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) to convey professionalism and trust, crucial for a billing system.
- Background color: Light Gray (#F0F0F0), a desaturated hue close to blue, to keep the interface clean and accessible.
- Accent color: Warm Orange (#FF9800), analogous to blue, to highlight calls to action.
- Body and headline font: 'PT Sans' (sans-serif) provides a modern look with a touch of warmth suitable for both headings and body text. 
- Use minimalist, clear icons to represent different inventory categories and actions (e.g., edit, delete, add).
- Employ a clean, well-organized layout with clear sections for inventory, billing, and settings. Utilize grid-based design for responsiveness.
- Incorporate subtle transitions and animations for user interactions (e.g., item selection, saving changes) to provide a smoother user experience.
